1. Si… alors… sinon

Dans Scratch, tu avais le bloc « si … alors … sinon ». En Python, cela s'écrit :

if condition:
    instructions si la condition est vraie
else:
    instructions sinon

Deux règles indispensables

  • la ligne if (et la ligne else) se termine par deux-points : ;
  • les instructions « dans » le if sont décalées de 4 espaces (touche Tab). C'est l'indentation : elle remplace la « mâchoire » du bloc Scratch.

Exécute cet exemple deux fois : une fois avec un âge de 15 ans, une fois avec 18.

input() renvoie toujours du texte. Pour comparer ou calculer avec un nombre, on le transforme : int(input(...)) pour un nombre entier, float(input(...)) pour un nombre à virgule.

2. Plusieurs cas : elif

elif (contraction de else if) permet d'enchaîner les cas. Python teste les conditions dans l'ordre et s'arrête à la première vraie.

3. Combiner des conditions : and, or

  • condition1 and condition2 : vrai si les deux sont vraies.
  • condition1 or condition2 : vrai si au moins une est vraie.
⚠️ Piège classique : couleur == "rouge" or "orange" ne fonctionne pas (Python le trouve toujours vrai !). Il faut répéter la comparaison : couleur == "rouge" or couleur == "orange".

ApplicationProjet B — Quiz d'arts appliqués

à faire

Pose 3 questions au joueur, compte les bonnes réponses dans une variable score (qui commence à 0) et affiche le score final sur 3. Exemples de questions :

  • Quelle couleur obtient-on en mélangeant du bleu et du jaune en peinture ? (vert)
  • En RVB, sur combien de couleurs se base l'écran ? (3)
  • Le format A4 mesure 21 cm sur … ? (29.7 ou 29,7 : accepte les deux réponses !)

Ajoute ensuite tes propres questions.

Coup de pouce

Pour ajouter un point : score = score + 1. Pour accepter les majuscules (« Vert ») : reponse = input("...").lower() transforme la réponse en minuscules.
